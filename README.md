# MULTIMÍDIA JVRS — Carbono Azul

Aplicativo inicial para Windows 10/11, com interface em português e navegação lateral.

## Estado desta versão
- Interface inicial e páginas de navegação: incluídas.
- Instalador Windows: gerado pelo GitHub Actions após execução bem-sucedida.
- Spotify, Bluetooth/telefone, GPS/mapas e telemetria ETS2: ainda não integrados; a interface informa isso claramente.
- Não inclui DLLs de terceiros nem bancos de áudio sem autorização de redistribuição.

## Gerar o instalador
No GitHub, abra **Actions → Build SETUP JVRS → Run workflow**. Ao concluir, baixe o artefato **SETUP_JVRS** na execução.
